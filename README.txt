Профіль Чіпки: HTML + CSS, без JavaScript.

1. Відкрийте index.html у браузері.
2. Обкладинки 8 пісень вставлені як реальні зображення через URL. Для їх відображення потрібен інтернет.
3. Щоб зробити сайт повністю офлайн, збережіть обкладинки самостійно з адрес src в HTML до папки images і змініть src на images/music-1.jpg ... images/music-8.jpg.
4. Попередні 9 дописів і коментарі збережені.
5. Для власних фотографій Чіпки можна створити папку images з файлами chipka-avatar.jpg, post-1.jpg ... post-9.jpg.
